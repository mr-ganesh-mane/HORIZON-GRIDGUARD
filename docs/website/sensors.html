Sensor System

Information about the sensors and hardware used by HORIZON GRIDGUARD.

℃

DHT11

The DHT11 is used to measure environmental temperature and relative humidity.

Measurement Temperature
Measurement Humidity
⚡

ESP32

The ESP32 collects readings from the DHT11 and communicates with the HORIZON GRIDGUARD REST API using Wi-Fi.

Communication Wi-Fi
Data Protocol REST API
⇄

REST API

The REST API provides communication between the ESP32 sensor system and the HORIZON GRIDGUARD website.

Method HTTP
Format JSON

DATA FLOW

DHT11  →  ESP32  →  REST API  →  HORIZON GRIDGUARD

Sensor readings are collected by the ESP32 and delivered to the monitoring platform through the REST API.
