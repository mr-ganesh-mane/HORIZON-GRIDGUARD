ABOUT THE PROJECT

HORIZON GRIDGUARD

A real-time environmental monitoring system built using ESP32, DHT11, REST API and a web-based dashboard.

OUR MISSION

Monitor. Connect. Protect.

HORIZON GRIDGUARD is designed to collect environmental data and make it available through an easy-to-use monitoring platform.

TECHNOLOGY

IoT + REST API + Web

The ESP32 collects temperature and humidity readings from the DHT11 sensor and communicates with the REST API over Wi-Fi.

SYSTEM ARCHITECTURE

How HORIZON GRIDGUARD Works

DHT11 Measures temperature and humidity
→
ESP32 Collects sensor data using Wi-Fi
→
REST API Receives and provides sensor readings
→
Website Displays live environmental data
